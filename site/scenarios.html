SCARLETEEL 2.0 — container RCE to cloud data theft

Exploits a public-facing container workload, lifts credentials from IMDSv1, then moves laterally into AWS, exfiltrates Terraform state and leaves a Lambda backdoor behind. The original cloud-native data-theft chain.

AMBERSQUID — multi-service cryptomining

CodefingerHalcyon RISE Team · Jan 2025

Codefinger — S3 ransomware via SSE-C

Harvests credentials from a public Terraform state bucket, enumerates S3, then re-encrypts objects with an attacker-held AES-256 SSE-C key and purges version history so there is nothing to roll back to. The data never leaves the account.

DangerDevInvictus IR · Jan 2024

DangerDev — leaked key to full account hijack

Bootstraps from a leaked long-term admin key and calls GetUser rather than GetCallerIdentity, dodging the identity-check fingerprint most rules watch for. Ends in cross-account trust backdoors, GPU mining recon and SES/Route53 phishing infrastructure.

ECScapeSweet Security research · 2025

ECScape — cross-task credential hijack in ECS

A deny-all task impersonates the ECS agent and harvests every co-resident task’s role and execution-role credentials from the same container instance. Task isolation is the control that fails.
